# 电商商品优化优先级分析项目

## 1. 项目背景

我们需要提升用户对店铺的整体体验，就需要优化商品，但运营资源有限，我们不能对于所有商品都优化。针对这一痛点，我们需要结合评分，找出那些影响大，范围广的商品，优先优化这些商品。可以做到高效，低成本，最大化的减少用户体验损失。

本项目基于订单、销售额和用户评价数据，构建商品优化优先级评分，帮助运营团队识别 P0、P1、P2、P3 不同优先级商品，为资源投入提供参考。

## 2. 业务问题

本项目主要解决以下问题：

1. 哪些商品影响面较大？
2. 哪些商品用户反馈较差？
3. 哪些商品应该优先投入资源优化？
4. 哪些商品可以暂时观察？

## 3. 数据来源

本项目使用 京东数据科学竞赛数据集，数据来源于和鲸Heywhale社区：
数据链接https://www.heywhale.com/mw/dataset/6628eb6b615a61f459767639/content?utm_source=chatgpt.com
由于该数据集为脱敏数据，店铺、商品、用户均以 ID 形式表示，因此本项目使用 shop_id、sku_id 等字段进行分析，不涉及真实店铺名和商品名。

本次分析非全量分析，只取特定商家进行分析


## 4. 分析思路

本项目不直接按照差评率或销售额单一指标排序，而是从两个维度综合判断商品优化优先级：


 订单量+销售额高代表着这个商品影响力广，
差评率+平均评分低代表着这个商品带给客户的体验不好
如果一个商品既有较大的影响面，又存在明显的用户体验问题，那么觉得体验不好的客户量是很庞大的，我们要着重优先处理这类商品


最终将商品划分为 P0、P1、P2、P3 四个等级。

## 5. 评分规则

商品优化优先级总评分由两部分组成：

商品优化优先级总评分 = 影响面得分 × 50% + 用户体验问题得分 × 50%

其中：

影响面得分 = 订单量得分 × 50% + 销售额得分 × 50%

用户体验问题得分 = 差评率得分 × 60% + 平均评分反向得分 × 40%

评分等级：

| 分数范围 | 优先级 | 含义 |
|---|---|---|
| 80分及以上 | P0 | 必须优先优化 |
| 65-79分 | P1 | 重点关注 |
| 50-64分 | P2 | 常规观察 |
| 50分以下 | P3 | 暂时放一放 |

## 6. 项目结果

项目最终输出商品优化优先级表，包括：

- 商品名称 / 商品ID
- 订单量
- 销售额
- 差评率
- 平均评分
- 影响面得分
- 用户体验问题得分
- 总评分
- 优先级等级

## 8. 项目结论

通过综合评分，本项目识别出一批 P0 商品。这类商品通常同时具备较大的订单量或销售额，并且用户反馈较差，因此应作为运营团队优先优化对象。

相比只看差评率或只看销售额，本项目的评分方式能更好地平衡“影响面”和“问题严重程度”，帮助运营团队在资源有限的情况下做出更合理的优化决策。

## 9. 项目局限

本项目主要用于判断商品优化优先级，不深入分析用户不满意的具体原因。

后续可以通过评价文本、退款原因、客服记录等数据，可以进一步分析用户不满意的具体原因，并提出更细化的优化方案。
